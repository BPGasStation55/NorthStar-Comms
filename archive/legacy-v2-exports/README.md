# Legacy Version 2 Exports

These files are preserved for migration history only.

They are **not approved for radio import**. The UV-5R and UV-32 files do not safely enforce every canonical receive-only restriction, and the UV-32 schema must not be treated as a DM-32UV schema.

Use only artifacts generated under `exports/test/` by the current scripts. No export becomes a production release until its profile records completed CPS import, radio programming and functional hardware validation.
