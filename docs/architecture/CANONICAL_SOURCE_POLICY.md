# Canonical Source Policy

## Authoritative source

`data/master_channels.csv` is the sole editable source for canonical channel positions and programming parameters in the current development baseline.

Radio exports must be generated by `scripts/build_exports.py`. Generated CSV files must never be edited manually.

## Workbook status

`database/master/Master_Radio_Database.xlsx` is retained as a legacy schema and provenance prototype. Its empty channel table is not an alternate source of truth.

The workbook may become a generated review interface after a deterministic import/export workflow is implemented. Until then:

- Do not manually populate its channel sheet.
- Do not use its placeholder export sheets.
- Do not treat workbook counts as release-readiness evidence.

## Change sequence

1. Update canonical data or a radio profile.
2. Run the validator.
3. Rebuild test artifacts.
4. Run the regression suite.
5. Review the Git diff.
6. Commit source and regenerated artifacts together.

## Stable identities

`NSC-###` identifies a canonical position. It is not a promise that every radio will use that same physical memory number. Radio-specific mappings may omit records or move them when hardware limits require it.
