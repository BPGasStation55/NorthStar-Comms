# NSC-EK01 — Compact Emergency Kit

**Status:** Selected concept; detailed integration pending
**Deployment target:** Under two minutes

EK01 is the compact Eylar-case emergency receive and RF-awareness kit. It is not GK01.

## Selected core

- Ulefone Armor 27T Pro+
- Anker battery pack
- One RTL-SDR Blog V4
- Telescopic antenna

## Preferred antenna accessories

- HF wire
- NOAA V-dipole
- ADS-B whip

## Mission

- Low-cost, low-power offline receive capability
- Local RF awareness
- NOAA weather monitoring
- Aircraft monitoring
- APRS monitoring where the software and receiver path support it

One SDR is the baseline. Multi-receiver operation, RSPdx-R2, HackRF and KrakenSDR are deferred to larger or specialist systems.
