# NSC-DD-001A — Primary Radio Ecosystem

**Status:** Selected direction
**Scope:** Future purchasing and integration
**Current owned radios:** Preserved

## Decision

Icom is the selected primary future radio ecosystem for NorthStar Comms.

The target architecture includes:

- A 50 W mobile radio for the primary vehicle.
- A future 50–100 W fixed base for Bavaria Road.
- Analog FM, APRS, GPS, offline maps, logging, repeaters and simplex as standard capabilities.
- Winlink, APRS messaging, cross-band repeat, digipeaters, D-STAR, VARA, JS8Call, ATAK, WinTAK, mesh and satellite messaging as planned capabilities.
- TAK Server and satellite phone integration as evaluation items.

## Existing equipment

Existing Baofeng radios remain supported for development, training, loaner, monitoring and transitional deployment roles.

DMR remains required but limited to the two existing DM-32UV radios:

- One allocated to GK01.
- One allocated to a mobile/base role.

Additional DMR radio purchases are not part of the current baseline.

## Exclusions

Amateur-radio encryption, Fusion, P25, NXDN and TETRA are not planned baseline capabilities.

Hardware model selections beyond the ecosystem direction require separate decision records and validation.
